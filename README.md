# Git and GitHub — A Beginner-Friendly Course

A practical, classroom-ready guide for learning **Git and GitHub**, designed to help students understand version control and develop the skills needed to manage, track, and share software projects effectively.

This course introduces students to the fundamentals of Git, explains how GitHub supports online repository hosting and collaboration, and guides them through the essential workflows used in modern software development.

Whether you are beginning your programming journey or looking to improve your development workflow, this guide provides a structured introduction to Git and GitHub through clear explanations and practical examples.

---

## About This Course

- Designed for beginner-friendly, classroom-based learning
- Combines conceptual explanations with practical commands and workflows
- Covers local version control and remote repository management
- Encourages hands-on practice with Git and GitHub
- Includes learning activities to reinforce essential commands and concepts
- Every session includes:
  1. **Summary**
  2. **Test Your Knowledge**
  3. **Try It Yourself**

---

## Purpose of this Guide

This guide have been carefully prepared in accordance with the **official course book provided to students through their Educational Course Material (ECM)**. The primary purpose is to help students make better use of their prescribed learning materials by making the concepts easier to understand, revise, and apply in practice.

Official books often contain extensive theoretical explanations. The guide complement the books by presenting the essential concepts in a **concise, summarized, and beginner-friendly format**, focusing on what students need to understand and practice.

Instead of lengthy theoretical discussions, each topic emphasizes:

- **To-the-point explanations** that make concepts easier to understand.
- **Relevant code snippets and examples** that demonstrate how concepts work.
- **Step-by-step practical demonstrations** to support hands-on learning.
- **Exercises and challenges** that encourage independent problem-solving.
- **Knowledge-check questions** to reinforce understanding and prepare students for assessments.
- **Summaries and revision material** to help students review important concepts efficiently.

**Important:** The guide are intended to complement the official course books, not replace them. Students should continue referring to their books for detailed theory, complete explanations, and the prescribed course content while using these guides for practical understanding, focused revision, and hands-on practice.

The goal is simple: **make the official course material more useful, understandable, and practical, helping students turn what they read into what they can actually do.**

## What You Will Learn

Throughout this course, students will develop an understanding of:

- Introduction to version control and its importance
- Understanding Git and GitHub
- Installing and configuring Git
- Creating and initializing repositories
- Understanding the working directory, staging area, and repository
- Tracking changes in project files
- Using essential Git commands
- Creating commits and reviewing project history
- Working with branches
- Connecting local repositories to remote repositories
- Creating and managing repositories on GitHub
- Pushing and pulling changes
- Cloning existing repositories
- Understanding collaboration and code-sharing workflows
- Managing project documentation with Markdown and `README.md`
- Publishing and maintaining projects using GitHub workflows, where covered by the guide

---

## Practical Learning Approach

This course emphasizes learning Git and GitHub by performing real version-control tasks.

Students are encouraged to:

- Execute Git commands themselves and understand their purpose.
- Create repositories for practice projects.
- Track file changes and create meaningful commits.
- Experiment with branches and understand why they are useful.
- Connect local projects to GitHub repositories.
- Practice synchronizing local and remote changes.
- Document projects using Markdown and README files.
- Review errors and understand how to resolve common Git problems.

The objective is to help students understand the workflow, not simply memorize commands.

## Course Structure

The guide is organized into progressive learning sessions that introduce version-control concepts and practical Git and GitHub workflows.

Students begin with the fundamentals and gradually develop the skills needed to manage repositories and work with project history.

For the latest lesson sequence, examples, and exercises, follow the session navigation available on the course website.

---

## Student Expectations

Students are expected to:

1. Read the lesson material carefully.
2. Understand the purpose of each command before executing it.
3. Practice Git commands using their own demonstration repositories.
4. Create commits that describe their changes clearly.
5. Practice repository and branch management.
6. Complete the **Try It Yourself** exercises.
7. Attempt the **Test Your Knowledge** questions.
8. Practice uploading and updating projects on GitHub.
9. Use version control consistently in their programming projects.

---

## Learning Outcome

By completing this guide and practicing the demonstrated workflows, students will understand the fundamentals of Git and GitHub and be able to track project changes, maintain repository history, manage branches, publish projects, and build confidence using version control in their development work.
